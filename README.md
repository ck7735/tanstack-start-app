# SVR Solutions Website

A modern website for SVR Solutions - providing CCTV installation, computer/laptop repair, and citizen government services in Hyderabad, India.

## Services

### IT Services
- CCTV Installation & Maintenance
- Computer Sales & Repair
- Laptop Sales & Repair
- Accessories & Networking

### Citizen Services
- Passport Application
- PAN Card Application
- Scholarship Application
- Marriage Certificate Application
- Kalyana Lakshmi Application
- Labour Department Services
- Trade Online Application
- Learning Licence Application
- Driving Licence Application

## Tech Stack

- **Framework**: TanStack Start (React)
- **Styling**: Tailwind CSS
- **Deployment**: Cloudflare Pages / Vercel / Netlify

## Getting Started

```bash
# Install dependencies
bun install

# Start development server
bun run dev

# Build for production
bun run build
```
